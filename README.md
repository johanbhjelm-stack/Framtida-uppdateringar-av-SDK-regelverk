# Framtida-uppdateringar-av-SDK-regelverk
Här finns versioner av SDKs dokumentation som kommer att införas i framtida releaser 
Om dokumenten är nya versioner av SDKs existerande dokumentation behåller de namnet från den nuvarande versionen. 

För att lägga till en ny fil, gå till "Add file" och välj "create new file". Ge filen ett namn, fyll den med innehåll, och välj "commit changes".
